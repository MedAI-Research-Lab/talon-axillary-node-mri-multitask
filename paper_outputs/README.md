# Publication outputs

`figures/main/` and `figures/supplementary/` contain the finalized manuscript graphics. Editable Draw.io architecture sources are in `figures/architecture/`. Main result tables and figure-selection/evidence metadata are included as CSV/JSON.

The aggregate performance figure and main tables can be regenerated using `scripts/reproduce_paper_outputs.py`. Clinical segmentation composites are frozen because their underlying private images and prediction arrays cannot be distributed.
