# Meme DCE-MRI'da IBC–IGM aksiller nod analizi için TALON

Bu klasör GitHub'a yüklenmeye hazır yayın paketidir. Kod, beş seed için anonimleştirilmiş dondurulmuş sonuçlar, makale tablo/şekilleri ve yeniden üretme notebookları bulunur. Ham MRI, maskeler, hasta adları, kimlik anahtarı, piksel tahmin dizileri ve model checkpointleri pakete alınmamıştır.

Makaledeki model adı **TALON**'dur; `HYBRID_TALON` yalnız yürütme sırasında kullanılan iç deney kimliğidir.

Kamuya açmadan önce `docs/DATA_GOVERNANCE.md` içindeki klinik görüntü izin kontrolünü tamamlayın ve `CITATION.cff` ile `LICENSE` dosyalarını nihai yazar/kurum kararına göre güncelleyin.
