# Data availability

The clinical imaging data are not publicly available because of institutional, ethical, and data-protection restrictions. Deidentified data may be available from the corresponding author upon reasonable request, subject to institutional approval and applicable ethical and data-protection requirements. The `splits/` directory contains sanitized, deidentified assignments and audits for the five repeated holdouts. To execute training, place institutionally authorized data under `data/private/` or point a local configuration to another protected location. `data/private/` is excluded by `.gitignore`.
